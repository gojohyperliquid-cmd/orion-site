# ORION

One-page interactive ORION website.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the project as a static site.
4. Deploy.

No build command is required.

## Local preview

Run:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Structure

- `index.html` — site
- `assets/orion-transformation.mp4` — mask → Orion animation
- `assets/orion-tiger.png` — Orion tiger
- `assets/orion-hypurr.png` — Orion × Hypurr artwork
- `assets/orion-reference.webp` — Orion reference image
